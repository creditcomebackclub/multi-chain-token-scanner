# Synthetic research data

`synthetic.csv` is generated by `research/ml/make_synthetic.py`. It contains no production observations, wallet-watch data, Telegram identifiers, credentials, or claims about strategy performance.

The generator uses fixed seed `20260930`, the exact export schema, repeated token/support groups, plausible feature distributions, and a deliberately weak planted relationship between a few point-in-time features and the TP1-first label. It exists only to exercise tests, notebooks, plots, and CI before a production snapshot is exported.

Generate it with:

```sh
python research/ml/make_synthetic.py
```

Synthetic results must never be copied into the portfolio README as empirical scanner performance.
